Documentation / Accessibility

Input parity belongs inside the renderer.

Interactive patterns expose the same preview, selection, focus, navigation, and teardown behavior across pointer and keyboard input.

Event navigation

Interactive event renderers use roving focus. Orientation-aware arrow keys move along time, Home and End move to boundaries, Enter or Space pins, and Escape clears.

Preview and selection

Hover and focus preview without mutating the pinned selection. Selection stays stable when orientation changes or compatible data is updated.

Overview controls

The linked overview exposes the viewport and both resize handles as separate focusable controls. Pointer and touch dragging use pointer capture; keyboard commands pan and resize with the same clamping rules.

Native reading order

The semantic feed remains a native chronological reading pattern. It deliberately avoids listbox semantics and synthetic arrow-key behavior.

Contextual Keyboard help

Each example generates its disclosure from that component's actual command set. Escape closes the disclosure and restores focus to its trigger.
