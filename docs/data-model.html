Documentation / Data model

Small records. Honest time.

Inputs stay immutable while renderers normalize timestamps, domains, and optional presentation fields.

Discrete events

Use { id, time, label }. Optional type, series, value, markerAxisOffset, and labelPlacement fields support grouping, aggregation, and deliberate label layout.

Ranges and journeys

Ranges use { id, start, end, label }. Relative journeys use { id, day, series, label }, where day is numeric and aligned to day zero.

Timestamp rules

Pass ISO strings, finite epoch milliseconds, or Date values. Reversed domains are normalized. Invalid timestamps throw rather than producing non-finite geometry.

Fixture boundary

Bundled fixtures are obviously fictional demonstrations, not templates for operational records or copied payloads.
