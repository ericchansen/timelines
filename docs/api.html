Scoped appearance

axisColor, axisWidth, labelAngle (-90° through 0° on horizontal datetime axes, applying one angle and one text-anchor to every tick), rug and marker options, aggregate stem/bar/head options, and labelGap apply to one renderer instance and clamp numeric values to finite bounds. Nine renderers honor labelAngle, and in overview-detail the overview strip and the detail axis share it so the two never disagree; relative-journeys, calendar-heatmap, and semantic-feed have no linear datetime axis and ignore it.

Tick ladders

Day axes snap to whole-week strides so labels land on the same weekday instead of drifting. Tick labels on a datetime axis carry data-tick-time, the tick's epoch milliseconds, for styling and assertions.

Shared core

createTimeScale, createTicks, selectResponsiveTicks, formatResponsiveTick, estimatedLabelWidth, createUtcInterval, aggregateTimeBuckets, normalizeAppearanceOptions, markerGeometry, layoutLabels, and range helpers are public exports.
