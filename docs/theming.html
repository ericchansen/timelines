Documentation / Theming

Change the theme, not the geometry.

Structural tokens and color tokens are separate contracts so visual organization never depends on hue.

Structural tokens

--tl-space-*, --tl-radius-*, --tl-hit-target, --tl-axis-width, --tl-marker-size, and --tl-motion-fast control layout and interaction geometry.

Theme tokens

--tl-color-page, --tl-color-surface, --tl-color-ink, --tl-color-muted, --tl-color-border, --tl-color-axis, and the accent tokens control appearance.

Override color safely

.my-timeline {
  --tl-color-accent: #245f5d;
  --tl-color-accent-strong: #174744;
  --tl-color-axis: #70797b;
}

Color overrides do not move marker centers, lane spacing, hit targets, or collision lanes. The catalog includes explicit light and dark themes and honors reduced-motion preferences.
