Documentation / Theming

Change the theme, not the geometry.

Structural tokens and color tokens are separate contracts so visual organization never depends on hue.

Structural tokens

--tl-space-*, --tl-radius-*, --tl-hit-target, --tl-axis-width, --tl-marker-size, and --tl-motion-fast control layout and interaction geometry.

Theme tokens

--tl-color-page, --tl-color-surface, --tl-color-ink, --tl-color-muted, --tl-color-border, --tl-color-axis, and the accent tokens control appearance.

Override color safely

.my-timeline {
  --tl-color-accent: #245f5d;
  --tl-color-accent-strong: #174744;
  --tl-color-axis: #70797b;
}

Color overrides do not move marker centers, lane spacing, hit targets, or collision lanes. The catalog includes explicit light and dark themes and honors reduced-motion preferences.

Horizontal datetime axes accept labelAngle from -90° through 0°. Every tick on an axis shares one angle and one text-anchor, and the axis reserves a left inset so the first rotated label stays inside the plot. Vertical tick labels remain horizontal.

Nine renderers draw a datetime tick axis and honor labelAngle. relative-journeys (elapsed-day axis), calendar-heatmap (weekday and month gutter), and semantic-feed (no axis) ignore it on purpose and show no angle control.

Customize one renderer

renderEventRug(element, {
  data,
  axisColor: "#70797b",
  axisWidth: 1.5,
  labelAngle: -45,
  rugColor: "#8f3550",
  rugWidth: 2,
  rugLength: 18
});

Renderer options write instance-local properties on generated content, so sibling timelines and global theme tokens stay unchanged.
