# Component catalog

The live GitHub Pages catalog registers twelve renderers from [`src/catalog-data.js`](../src/catalog-data.js). Each component page is generated by one shared page shell and includes a live visualization, usage guidance, data shape, relevant options, minimal code, source/API links, scenario controls, and contextual keyboard help.

Open [`index.html`](../index.html) through a static server rather than `file://` so native ES module imports resolve correctly.
