Example guide

Four focused references share one synthetic fixture and one dependency-free CSS and JavaScript core.

Choose a pattern

Basic proportional timeline

Use for a small event set where elapsed time matters. Marker positions come from timestamps, and the axis becomes a vertical sequence on narrow screens.

Overview and detail

Use when a reader needs both the full time span and a movable detail window. Drag the viewport to pan, drag either handle to resize, or use the equivalent keyboard controls. The range never becomes shorter than 20 minutes.

Semantic feed

Use for reading and scanning grouped activity. This pattern is intentionally non-interactive. Categories differ by headings, badges, initials, and solid or dashed line geometry.

Keyboard navigation

Use as a reference for listbox-style roving focus. Up and Down move focus, Home and End jump, and Enter or Space pins an item without conflating focus with selection.

Include the shared core

Pages load the shared geometry and behavior directly, with project-relative paths that also work under the /timelines/ GitHub Pages site.

<link rel="stylesheet" href="../src/timeline/timeline.css">
<script src="../src/timeline/timeline.js"></script>
<script src="../src/fixtures/synthetic-events.js"></script>

The browser globals are TimelineKit and SYNTHETIC_TIMELINE_EVENTS. The JavaScript core also supports CommonJS for dependency-free unit tests.

Theme without changing geometry

Shared --tl-* variables control spacing, hit targets, axis thickness, and layout. Theme aliases consume the page-level --cp-* color variables. Override the color variables without moving markers, changing category organization, or weakening focus geometry.

Test locally

Run npm test for range math, syntax, and project-relative link checks. Run npm run dev, then open http://localhost:8000/ for browser testing.
