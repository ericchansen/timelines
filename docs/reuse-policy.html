Synthetic-only reuse policy

This repository is designed for public reuse. Every committed example and fixture must be safe to publish without private context.

What belongs here

  • Reusable timeline source code
  • Obviously fictional event fixtures
  • Interaction and accessibility documentation
  • Documentation-only static assets

What does not

  • Real names, accounts, or customer IDs
  • Production telemetry or payloads
  • Internal operational details
  • Data copied from private systems

Fixture guidelines

Use simple identifiers such as evt-001, neutral descriptions such as “synthetic release sequence,” and clearly demo-grade timestamps. Treat uncertainty as a reason to replace data, not to publish it.
